최신 로컬 개발 추가 — v0.23.1:
사용자가 홈 미리보기에서 간헐적으로 로봇이 지글거리는 문제를 제보했다. 화면 왕복 후 이미 폐기된 Go2 canvas에 지연 contextlost 이벤트를 모의 전달하면 현재 홈의 세 모델이 모두 WebGL→SVG로 전환되는 경로를 재현했다. 이전 canvas는 DOM에서 제거됐으나 실제 WebGL 컨텍스트가 살아 있었고 이벤트 감시도 남아 있었다.
src/ui/renderer3d.js에 watchRendererContext와 disposeRenderer3D를 추가했다. disposed 뷰의 이벤트는 무시하고 해제 콜백으로 감시를 제거한다. 렌더러 dispose 뒤 아직 살아 있는 native 컨텍스트에 forceContextLoss를 적용해 GC 시점에 의존하지 않는다. 이미 끊긴 컨텍스트를 중복 해제하지 않는다.

2. 현재 목표와 최종 교육 구성

목표는 여러 군용 로봇의 기초 정비와 운용 준비를 연습하는 교육 플랫폼이다.

기본 입력은 일반 노트북의 마우스·키보드·터치패드이며 Unity·Unreal은 사용하지 않는다.
실기체를 제어하거나 실제 비행을 가르치는 프로그램으로 설명하지 않는다.
식수 적재는 11월 6일 사용자가 제외한 범위다.

첫 화면에는 드론 정비 교육 / 사족보행 로봇 정비 교육 두 선택지를 둔다.
장비를 선택하면 교육 설명과 회전·확대 가능한 3D 미리보기를 보여주며,
실습 시작을 눌러야 실제 교육이 시작된다. 조종기 교육은 각 장비 안에 배치한다.

드론 정비: 전원·배터리 안전 확인 → 네 모터 상태 판단 → 날개 쌍·나사 교체 →
나사 체결 → 최종 확인 세 항목 → 정비 완료. 배터리 교체와 일자 잔량 LED도 제공한다.
사족보행 정비: 안전 준비 → 네 다리 점검 → 관절 모듈 교체 → 작동 확인.

모듈을 놓은 뒤 볼트 두 개와 커넥터까지 마무리해야 시험할 수 있다.
로봇 조종기: 전원·연결·비상정지 해제 → 이동·회전 → 정지 → 비상정지.
입력에 따라 3D 보행·위치·방향을 간소화하여 표시한다.

3. 3D 정비 조작과 안내

정비 조작은 3D 작업대 안의 공구·나사·볼트·커넥터·배터리·날개·관절 모듈에서 수행한다.
공구를 대면 분리·체결을 표시하며 집은 부품은 포인터를 따라 움직인다.
현재 할 일 한 가지·다음 대상·남은 작업을 안내하고 완료 조건을 대신 수행하지 않는다.
현재 작업과 3D 대상은 초록색 안내 상자와 밝게 퍼지는 조작 고리로 강조하며 도움말 현재 행에는 '지금'을 표시한다.
한국어 음성 안내는 현재 작업·설명·조작 대상을 읽고, 음소거·다시 듣기를 제공한다.
실제 소리는 접속 PC의 브라우저·한국어 음성 지원에 따라 달라진다.

WebGL을 기본으로 사용하고 실패하면 SVG 호환 표시로 전환한다.
사용자는 WebGL 적용 후 화면이 깔끔해졌다고 확인했다. 과거 SVG 기본 설정 설명보다 이 결정이 우선한다.
자동 검사 환경에서는 실제 GPU 초기화가 멈춰 호환 모드로 기능을 검사했다.
그 이유만으로 WebGL 기본 설정을 되돌리지 않는다.

4. 드론 조종기와 IMU — 최종 통합 결정

IMU 독립 메뉴는 제거했다. 조종기 작동 확인 → IMU 보정을 한 과정으로 제공한다.
조종기 확인만으로는 전체 교육 완료가 아니며 두 단계를 모두 마쳐야 완료한다.
다시 시작은 IMU 단계에서도 조종기 교육 처음부터 전체 과정을 초기화한다.

IMU는 교육용 가상 보정이다. 여섯 목표 자세 각각에서 3초간 정지해야 측정한다.
잘못된 자세나 기체 움직임은 현재 자세의 홀드 시간을 초기화한다.
도움말·창 초점 상실·탭 숨김 등에서는 일시정지하고 사용자가 명시적으로 재개해야 한다.
측정한 자세는 유지하며 여섯 자세 후 수평으로 되돌리고 결과를 확인해야 완료한다.
실제 센서·특정 DJI Mini 2 SE의 제조사 보정 절차를 그대로 재현했다고 주장하지 않는다.

사족보행 관절 보정은 필요성과 개선안을 설명했을 뿐 추가 구현 승인은 없다.
일상 시작 절차와 필요할 때의 보정을 구분하며, 매번 전원 켤 때 전체 수동 보정이 필요하다고 일반화하지 않는다.

5. 완료 표시와 최신 버그 수정

모든 교육의 최종 완료 시 화면 중앙에 큰 '교육을 마쳤습니다!' 모달을 표시한다.
어두운 배경·큰 체크·확인 버튼을 사용한다. 같은 시도에서는 다시 표시하지 않고 새 시도 완료 시 다시 표시한다.
확인 또는 Esc로 닫아도 결과는 유지한다. 드론 조종기는 IMU까지 끝나야 모달을 표시한다.

최신 원본 버전은 v0.11.3이다. 마지막 수정은 src/ui/spatial-maintenance.js의 스페어 날개 표시다.
장착 날개의 group.clone(true)가 상위 visible=false까지 복사해 스페어 모형이 숨겨지던 것을
model.visible=true로 고쳤다. 손상 날개 수거·집기 취소·잘못 놓기·포장 전환에도 스페어가 보이고,
실제로 장착한 새 날개만 재고에서 사라져야 한다.
